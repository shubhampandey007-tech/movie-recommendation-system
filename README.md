# Movie Recommendation System

An AI-based movie recommendation system built in Python that suggests movies to users based on similarity in genres, ratings, and other movie attributes.

## Features
- Recommends movies similar to a given movie/title
- Uses content-based filtering on a movie dataset (CSV)
- Built and tested in Python

## Tech Stack
- Python
- Pandas (data handling)
- CSV dataset for movie metadata
